# Prompts del gancho

[← Volver al paso 1](README.md)

Los tres siguen la misma receta: **rol, contexto, tarea y formato**. Se vota uno de los tres y, en el mismo chat, se pide el aviso para los tutores.

## 1. Ciclo del agua (animación por pasos)

```
Eres diseñador de materiales educativos para secundaria en México.
Contexto: doy Ciencias en una telesecundaria. Mis alumnos leen poco texto, así que necesito palabras sencillas y frases cortas.
Tarea: crea una animación interactiva del ciclo del agua con 4 pasos: evaporación, condensación, precipitación, escurrimiento e infiltración. Cada paso se activa con un botón y anima la escena. Incluye un botón para reproducir todo el ciclo.
Formato: una sola página web (un solo archivo HTML), letras grandes para verse en proyector, todo en español, máximo 2 frases por paso.
```

## 2. Independencia de México (línea del tiempo)

```
Eres diseñador de materiales educativos para secundaria en México.
Contexto: doy Historia en una telesecundaria. Mis alumnos se pierden con tantas fechas y personajes, así que necesito algo visual y frases cortas.
Tarea: crea una línea del tiempo interactiva de la Independencia de México, de 1810 a 1821, con al menos 6 momentos clave. Al hacer clic en cada momento se muestra la fecha, qué pasó y quién participó, en máximo 2 frases, con una ilustración sencilla dibujada dentro de la página (por ejemplo, una campana, una bandera o un mapa). Incluye botones de anterior y siguiente para recorrerla en orden. El cambio entre momentos debe ser animado y los botones deben moverse al pasar el mouse y al hacer clic.
Formato: una sola página web (un solo archivo HTML), con colores, sombras y profundidad para que no se vea plana, letras grandes para verse en proyector, todo en español.
```

## 3. Prismas (3D y desarrollo plano)

```
Eres profesor de matemáticas de secundaria en México.
Contexto: doy Matemáticas en una telesecundaria. Mis alumnos están viendo prismas y les cuesta imaginar cómo se arma un prisma a partir de su desarrollo plano.
Tarea: crea una herramienta interactiva con dos vistas lado a lado: a la izquierda, un prisma en 3D que se pueda girar con el mouse; a la derecha, su desarrollo plano en 2D. Cada cara debe tener el mismo color en las dos vistas para que se vea cuál es cuál. Incluye botones para elegir el prisma: triangular, rectangular, pentagonal y hexagonal. Si es posible, agrega un botón que anime cómo se desdobla el prisma.
Formato: una sola página web (un solo archivo HTML), letras grandes, todo en español.
```

## Aviso para los tutores (en el mismo chat)

Después de la animación, sin abrir un chat nuevo:

```
Ahora redacta un aviso para los padres de familia y tutores. Los alumnos van a presentar una exposición sobre este tema usando esta animación. Usa estos datos: Escuela Telesecundaria "Ejemplo", el viernes 5 de diciembre a las 10:00 en el salón de usos múltiples, firma la dirección. Tono formal pero amable, máximo media página, listo para imprimir.
```

> Fíjate que no le repetimos el tema: **la conversación recuerda** lo que ya hablamos.
