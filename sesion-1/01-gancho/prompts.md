# Prompts del gancho

[← Volver al paso 1](README.md)

Los tres siguen la misma receta: **rol, contexto, tarea y formato**.

## 1. Ciclo del agua (animación por pasos)

```
Eres diseñador de materiales educativos para secundaria en México.
Contexto: doy Ciencias a 1.° de secundaria (12-13 años) en una telesecundaria. Mis alumnos leen poco texto, así que necesito palabras sencillas y frases cortas.
Tarea: crea una animación interactiva del ciclo del agua con 4 pasos: evaporación, condensación, precipitación, escurrimiento e infiltración. Cada paso se activa con un botón y anima la escena. Incluye un botón para reproducir todo el ciclo.
Formato: una sola página web (un solo archivo HTML), letras grandes para verse en proyector, todo en español, máximo 2 frases por paso.
```

## 2. Célula animal (diagrama con clic)

```
Eres diseñador de materiales educativos para secundaria en México.
Contexto: doy Biología a 1.° de secundaria (12-13 años). Mis alumnos están viendo la célula por primera vez y necesito lenguaje muy sencillo.
Tarea: crea un diagrama interactivo de una célula animal con núcleo, mitocondrias, ribosomas, aparato de Golgi, citoplasma y membrana. Al tocar cada parte debe resaltarse y mostrar su nombre y qué hace en una frase corta. Aclara que es un esquema simplificado.
Formato: una sola página web (un solo archivo HTML), que se pueda usar con el teclado, letras grandes, todo en español.
```

## 3. Ecuaciones de primer grado (práctica con retroalimentación)

```
Eres profesor de matemáticas de secundaria en México.
Contexto: mis alumnos de 1.° y 2.° de secundaria apenas están aprendiendo a resolver ecuaciones de primer grado como 3x + 5 = 20. Se les olvida que lo que se hace de un lado se hace del otro.
Tarea: crea una práctica interactiva donde el alumno resuelva la ecuación paso a paso eligiendo la operación correcta. Si elige mal, que la página explique por qué en una frase. Al final debe comprobar el resultado. Genera ecuaciones nuevas cada vez, siempre con respuesta entera.
Formato: una sola página web (un solo archivo HTML), letras grandes, todo en español.
```
