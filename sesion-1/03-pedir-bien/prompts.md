# Prompts del paso 3

[← Volver al paso 3](README.md)

Cada perfil tiene un prompt **malo** y uno **bueno**. Escribe primero el malo y después el bueno, en **chats separados**: si mandas el bueno en el mismo chat, la IA ya sabe lo que querías y la comparación no es justa.

## Docentes: muy técnico para niños

**Malo:**

```
Explícame la fotosíntesis.
```

**Bueno:**

```
Eres profesor de Ciencias de secundaria en México.
Contexto: doy clases en una telesecundaria. Mis alumnos leen poco y se pierden con palabras técnicas.
Tarea: explícales la fotosíntesis como si fuera una receta de cocina: ingredientes, dónde se cocina y qué sale.
Formato: máximo 6 frases cortas y una pregunta al final para ver si entendieron.
```

## Secretarias y directivos: oficio genérico

**Malo:**

```
Hazme un oficio para pedir permiso.
```

**Bueno:**

```
Eres secretaria de una escuela secundaria en México.
Contexto: trabajo en la dirección de la Telesecundaria "Ejemplo". Los oficios se dirigen a la Supervisión Escolar y los firma el director.
Tarea: redacta un oficio para pedir permiso de salir con los alumnos de tercero a una visita al museo el viernes 28 de noviembre, de 9:00 a 13:00.
Formato: entrégamelo como documento de Word (.docx), tamaño carta, listo para imprimir: número de oficio, lugar y fecha, asunto, destinatario, cuerpo de máximo dos párrafos, despedida y espacio para la firma.
```
