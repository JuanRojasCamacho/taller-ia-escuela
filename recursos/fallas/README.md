# Casos donde la IA falla

La IA no es perfecta. Hay dos tipos de fallas:

- **Tipo A, se arreglan con el prompt:** pasan por falta de contexto. Se ven en la [sesión 1](../../sesion-1/03-pedir-bien/).
- **Tipo B, inventa aunque el prompt sea bueno:** la única defensa es revisar. Se ven en la [sesión 2](../../sesion-2/).

| Tipo | Caso | Lección |
| --- | --- | --- |
| A | Muy técnico para niños | Sin contexto, la IA habla para cualquiera, no para tus alumnos |
| A | Oficio genérico | Si no le das tu formato, inventa uno que no es el de tu escuela |
| B | Contar letras | La IA no ve letras, ve pedazos de palabras (tokens) |
| B | Premisa falsa | Si le das un dato equivocado, puede construir sobre él |
| B | Algo local | Lo que no está en internet, se lo inventa |

> Las IA cambian y no siempre fallan igual. Cada caso se prueba antes del taller y se guarda una captura.
