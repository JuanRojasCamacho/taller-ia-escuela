# Sesión 2: Dar contexto

> La sesión pasada le dijiste a la IA quién eres. Hoy le vas a dar **lo que sabes**: el libro, tus apuntes y tus formatos.

**Duración:** 180 minutos · *Borrador: se arma después de la sesión 1.*

| | Descanso | 15 | |
